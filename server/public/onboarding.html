Welcome to Twilio Dialer!

Getting Started

Thank you for installing the Twilio Dialer Chrome extension. This extension allows you to make and receive calls directly from your browser using Twilio's Voice API.

Setup Instructions

1. Server Configuration

The extension requires a backend server for Twilio authentication. The server is already running at http://localhost:3000.

If you need to customize the server configuration, you can edit the .env file in the server directory: 

# Twilio Credentials
TWILIO_ACCOUNT_SID=AC1ca93006ce71b64875e83739904abd75
TWILIO_AUTH_TOKEN=d3a025d142f7bf2dd173cb85c6c4e3b8
TWILIO_API_KEY=your_twilio_api_key
TWILIO_API_SECRET=your_twilio_api_secret

# TwiML App SID (optional)
TWILIO_TWIML_APP_SID=your_twiml_app_sid

# Server configuration
PORT=3000
SERVER_BASE_URL=http://localhost:3000

2. Using the Extension

  • Make Calls: Click the extension icon, enter a phone number, and click the "Call" button.
  • Receive Calls: When someone calls your Twilio number, you'll receive a notification and can answer from the extension popup.
  • Caller ID: By default, calls will use the number +1 978 878 5223. You can add more caller IDs in the server configuration.
Note: For incoming calls to work, you need to configure your Twilio phone number to point to your server's webhook URL: http://your-server-url/voice

3. Advanced Configuration

For production use, you should:

  • Host the server on a publicly accessible URL
  • Set up a TwiML Application in your Twilio console
  • Configure your Twilio phone numbers to use the TwiML Application
  • Update the server's environment variables accordingly
